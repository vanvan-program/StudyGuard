# StudyGuard 安装与使用

正式版 **0.3.8**，适用于 Android 8.0 及以上，包名为 `io.studyguard.app`。

## 安装

1. 从 [StudyGuard Releases](https://github.com/vanvan-program/StudyGuard/releases/tag/v0.3.8) 下载 `StudyGuard-0.3.8-release.apk` 到安卓手机。
2. 用文件管理器打开；如系统询问，临时允许该文件管理器安装未知应用。
3. 核对名称StudyGuard后安装，之后可关闭安装未知应用权限。

无需Root、ADB、Shizuku或设备管理。独立包名不覆盖FocusForcePlus。
后续覆盖安装需相同签名。如提示签名不一致，请先确认数据保存方案，不要直接卸载。
从 0.3.8 起，打开「设置 → 应用更新」，点「检查更新」再下载。默认先尝试 GitHub，超时或持续低速时尝试 gh-proxy.com、ghfast.top。也可固定一条线路。应用校验大小、SHA-256、包名、版本和签名后，由你授权系统安装。安装前请结束当前学习。

## 权限与应用选择

在“设置”阅读说明，再按需操作：

- 使用情况访问：观察前台应用切换，缺失或撤销时停止累计受监督时长并解除限制。
- 通知：展示状态、检查提醒和通知栏紧急结束。关闭后可能看不到提醒。
- 无障碍增强（可选）：仅读窗口包名，不读文字、输入或浏览页面；尝试返回桌面和显示提醒，不能保证拦截成功。
- 受限娱乐应用：自己选择需要限制的应用。
- 允许的学习应用：选择需要计入手机学习时间的题库、教材等应用。「不受限」只放行。升级后请重新勾选学习应用，旧混合名单默认只放行。

选择和检查间隔在下一次会话生效，通信、桌面、系统权限设置始终放行。
各品牌菜单不同，可在系统设置搜索“使用情况访问”“无障碍”“通知”。此处不提供未经真机验证的固定菜单路径。
App不会自动授予权限，不阻止撤销、强停或卸载。

## 学习与退出

填写科目、1–720分钟时长，选择纸书或手机模式，手动开始。
在 0.3.7-dev 中，首次使用可直接点「去开启监督权限」。返回后会保留刚填的科目、时长和关联任务，再点「开始学习」即可计时。
纸书模式锁屏本身不算分心，但长观测缺口仍中断计时。
手机模式仅累计本应用及白名单学习应用中的时间，锁屏/非学习应用/未知区间不计入。
没有无障碍连接时只监测和通知，不冒称强拦截。
可随时暂停、提前结束或紧急解除，原因可不填，无密码或等待。
强停/重启/进程死亡后限制失效，再次打开需手动恢复，不补算未知时间。
学习监督运行时使用有超时的CPU唤醒锁维持锁屏观察，可能增加耗电；暂停、中断、权限丢失和退出时释放。它不能保证厂商不会清理后台。

## 计划与统计

输入目标、科目、每日时间和进度，并通过日历选择考试日期，生成未来最多7天草案。
0.3.7-dev 的学习页按标题展示今日任务。补做往期任务时，在计划页选择对应日期或「全部日期」，点任务卡的「开始学习」即可带入科目和剩余时长。
一个任务可以分几段学习。每段达标后选择「下次继续」保留进度，或点「任务已完成」打卡。锁屏期间达标，会在返回应用时询问。提前结束时仍可自行勾选完成任务。
当前明确标为本地规则，不是真实大模型输出。检查后加入，可编辑、删除和改期；已有同日同科任务保留。
检查默认每30分钟**有效学习**触发，可设置1–180分钟，系统可能延迟；自报进度不自动代表任务完成。
统计包含有效时长、科目、完成率、访问受限应用、提前结束、日趋势和本地日总结。
每天累计至少1分钟有效学习计作一天打卡。

## 数据

学习功能离线运行，只有主动检查或下载更新时才联网。系统备份与设备转移排除应用数据，卸载会删除数据。
设置页可导出未加密的完整学习备份，。恢复前可核对备份日期、备份与本机的任务数和有效时长，再确认是否覆盖恢复学习设置、任务、会话、分段、事件和总结；原版普通待办不受覆盖。
备份由系统文档选择器写入或读取，应用不自行上传。请选择可信的本机文件；云盘提供方可能同步文件。
从 0.3.6-dev 起，学习任务与原版待办独立保存。覆盖安装会迁移尚存的学习任务，保留完成状态、完成时间和会话关联。学习任务请在 StudyGuard 设置中备份或恢复，原版工具的备份只管理原版数据。0.3.4-dev 和 0.3.5-dev 导出的 StudyGuard 学习备份仍可恢复。
开发版尚未完成系统/品牌运行验收，不宜作为唯一的重要记录载体。完整边界见兼容性与测试矩阵。
